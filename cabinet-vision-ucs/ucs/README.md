# UCS files

One file per UCS, in a folder per category: `ucs/<CATEGORY>/<CAT - Name>.txt`
(for example `ucs/VAN/VAN - Floating Vanity.txt`).

Each file holds the exact code as pasted into Cabinet Vision, starting with the header block
from `templates/new-ucs.txt`.

| Folder | Category |
|---|---|
| `VAN` | Vanities |
| `BASE` | Base cabinets |
| `UPR` | Uppers |
| `TALL` | Tall cabinets |
| `DRW` | Drawers |
| `SHF` | Shelves |
| `DOOR` | Doors |
| `CNC` | Machining / operations |
| `LBL` | Labels / reports |
| `GEN` | General |

Folders are created when their first UCS arrives. No UCSs recorded yet.
