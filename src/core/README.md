# core

The master copy format (Zod schemas), the base unit (1/64 inch, DECISIONS U-1) and conversions, the angle convention, generic geometry, layout checks and the validation interface (BUILD_SPEC 5.2).

**Pure:** no database, network, React, clock or randomness. It imports nothing but `zod`. The checks in `npm run check` enforce this.
