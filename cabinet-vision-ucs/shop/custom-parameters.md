# Custom parameters

before creating a new name; add every new name in the same commit as the UCS that creates it.

Prefix: `MT_` for persistent parameters (placeholder until the shop chooses one), `t_` for
temporary parameters (deleted by the end of the UCS, so they're not listed here).
